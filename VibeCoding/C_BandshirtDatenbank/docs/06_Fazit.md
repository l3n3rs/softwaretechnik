# Fazit

## Vorgehen und Fazit

Die während der Entwicklung verwendeten Prompts sind in der Datei `=5_Prompts.md` dokumentiert.

Für die Umsetzung habe ich erneut Codex verwendet und dieses Mal direkt in Visual Studio Code eingebunden. Die Nutzung der Entwicklungsumgebung ist im beigefügten Screenshot festgehalten.

Im Vergleich zu Aufgabe B habe ich Codex dieses Mal umfangreicher eingesetzt. Die KI wurde nicht nur zur Erstellung einzelner Funktionen verwendet, sondern auch für den Entwurf der verteilten Architektur und die Aufteilung der Anwendung in mehrere Prozesse und Module.

Die konkrete Arbeitsweise in Visual Studio Code unterschied sich für mich dennoch nur wenig von Aufgabe B. Aus der Aufgabenstellung war für mich deshalb nicht eindeutig erkennbar, welche zusätzliche oder andere Nutzung einer CLI beziehungsweise eines Visual-Studio-Code-ähnlichen Werkzeugs in Aufgabe C erwartet wurde.

Auch aus der Aufzeichnung der Veranstaltung ging für mich nicht klar hervor, welcher konkrete Nachweis oder welche besondere Arbeitsweise an dieser Stelle gefordert war. Für zukünftige Aufgabenstellungen wäre daher eine genauere Beschreibung hilfreich, beispielsweise mit einem kurzen Beispiel dafür, was bei der Nutzung einer CLI oder eines Visual-Studio-Code-Clones konkret gezeigt werden soll.

Wie bei der Aufgabe B habe ich Codex darum gebeten den Code zu kommentieren. Da mir das nicht ausgereicht hat, habe ich den Code nachträglich separat mit der KI ausführlicher kommentieren lassen. Natürlich wäre in der Realität ein derart exessiv kommentierter Code eher unüblich und wahrscheinlich hinderlich.
