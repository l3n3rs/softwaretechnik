# – Projektidee

Im Rahmen vorheriger Aufgaben in diesem Modul wurde bereits eine Banddatenbank für einen Verein konzipiert. Dazu wurden unter anderem eine Analyse, Requirements, UML-Diagramme sowie ein erster GUI-Prototyp erstellt.

In dieser Aufgabe soll das bestehende Konzept als größere verteilte Anwendung weiterentwickelt werden. Der Schwerpunkt liegt dabei nicht auf einer vollständig lauffähigen Implementierung, sondern auf einer sinnvollen Architektur sowie dem Verständnis des erzeugten Codes.

## Anforderungen

Das System soll unter anderem folgende Funktionen bereitstellen:

- Bands anlegen
- Bands bearbeiten
- Bands löschen
- Bands suchen
- Bands nach verschiedenen Kriterien filtern
- Recherche-Status verwalten
- Kommentare und Quellen hinterlegen
- Änderungen nachvollziehbar dokumentieren
- Export einer Bandübersicht ermöglichen

Jede Band besitzt mindestens folgende Informationen:

- Primärer Bandname
- Sekundäre Bandnamen
- Recherche-Status
- Quellen
- Kommentare
- Ersteller
- Bearbeiter der letzten Änderung
- Datum der letzten Änderung
