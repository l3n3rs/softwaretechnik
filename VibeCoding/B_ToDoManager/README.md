# ToDo Manager

Eine einfache lokal lauffähige ToDo-Webanwendung mit HTML, CSS, JavaScript und LocalStorage.

## Projektstruktur

```text
B_ToDoManager/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── docs/
```

## Lokale Ausführung

Das Projekt benötigt keinen Server und kein Framework.

Öffne einfach die Datei `index.html` direkt im Browser.

## Funktionen

- Aufgaben hinzufügen
- Priorität pro Aufgabe setzen
- Fälligkeitsdatum pro Aufgabe setzen
- Aufgaben als erledigt markieren
- Einzelne Aufgaben löschen
- Alle erledigten Aufgaben löschen
- Nach Fälligkeitsdatum sortieren
- Nach Priorität sortieren
- Nach Priorität filtern
- Aufgaben dauerhaft im LocalStorage speichern

## Dokumentation

Im Ordner docs/ befindet sich die Dokumentation des Projekts.

Die Dateien beschreiben:
- 01_Idee.md – Projektidee und Zielsetzung
- 02_GUI.md – Bezug zum GUI-Entwurf aus Aufgabe A
- 03_Projektstruktur.md – Aufbau der Dateien und Ordner
- 04_prompts.md – Konversation mit Codex
- 05_Implementierung.md – Umsetzungsschritte mit Codex (Datei automatisch erstellt und gefüllt von Codex)
- 06_Fazit.md – Reflexion und Fazit zur Umsetzung
