
## Projektidee

Der ToDo Manager ist eine kleine lokal lauffähige Webanwendung zur Verwaltung meiner Aufgaben.

Ich kann Aufgaben erstellen, bearbeiten, löschen und als erledigt markieren. Außerdem können Aufgaben nach Status, Priorität und Fälligkeitsdatum sortiert oder gefiltert werden.

## Verwendete Technologien

- HTML
- CSS
- JavaScript
- LocalStorage

## Funktionen

Die Anwendung bietet folgende Funktionen:

- Aufgabe hinzufügen
- Aufgabe löschen
- Aufgabe als erledigt markieren
- Priorität vergeben
- Fälligkeitsdatum setzen
- Aufgaben filtern
- Aufgaben sortieren
- lokale Speicherung im Browser
