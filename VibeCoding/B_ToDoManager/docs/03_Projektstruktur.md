# Projektstruktur

Die Anwendung ist bewusst einfach aufgebaut und besteht aus drei Hauptdateien.

```text
B_ToDoManager/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── docs/
```

## Dateien

- `index.html`: Enthält die sichtbare Struktur der Webanwendung.
- `css/style.css`: Enthält das komplette Styling.
- `js/script.js`: Enthält die Logik für Aufgaben und LocalStorage.

Die App kann direkt über `index.html` im Browser gestartet werden.
